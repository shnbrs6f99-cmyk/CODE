# Roadmap Maintenance Policy

The GitHub issue **Master Development Roadmap** is the canonical project tracker and is mirrored in `/ROADMAP.md`.

## Codex requirements

1. Update the issue and `ROADMAP.md` after every meaningful completed module.
2. Mark a checkbox complete only when implementation, automated tests where applicable, and documentation are committed.
3. Add the relevant commit SHA or pull request reference to every completion update.
4. Add newly discovered work instead of silently omitting it.
5. Never mark commercial readiness complete while critical or high-severity defects remain.
6. Keep incomplete, blocked, and deferred items visible with a brief reason.
