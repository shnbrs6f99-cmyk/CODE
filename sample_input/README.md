# Sample Input

Place **sanitized Tally Prime ledger PDFs** in this folder for testing.

No real customer ledger is included because ledger PDFs contain confidential financial information. Before sharing a PDF for parser improvement, remove or replace customer names, addresses, GST numbers, bank details, invoice references, and commercially sensitive amounts where possible.

The desktop application does not require PDFs to be stored here; this folder is only a predictable location for validation exercises.
